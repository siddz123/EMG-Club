# EMG Club Website

Website for the Emerging Markets Group (EMG), a student organization at Indiana University.
Live domain: emergingmarketsclub.org (see `CNAME`).

## Files
- `index.html`: Home
- `about.html`: About (placeholder layout; Sam is drafting the content)
- `program.html`: Analyst program, capstone, research publication
- `research.html`: Research publication (coming soon)
- `join.html`: Culture, expectations, recruitment timeline
- `team.html`: Founders and faculty advisor
- `contact.html`: Contact
- `styles.css`: colors, fonts and layout (change colors at the top)
- `fonts/`: Jost web font (SIL Open Font License, see `fonts/LICENSE-Jost.txt`)

Each page repeats the same header and footer. If you add or rename a page, update the nav in every file.
Placeholders are marked `<span class="ph">[LIKE THIS]</span>` and show highlighted in yellow until filled in.

## Working together
- Split the work by page or section so you don't edit the same part at the same time.
- Before you start, pull the latest version (ask Claude: "get the latest version first").
- After you finish a piece, save it to GitHub (ask Claude: "commit and push my changes").

## Content rules
- Don't name outside professors, practitioners, firms or other clubs as advisors, partners or endorsers.
- No IU or Kelley logos or official branding; describe EMG as a student organization at IU.
- No invented statistics, member counts, testimonials, placements, events or past activity.
